Frontend (React + Vite)

Build

cd "C:\1. Personal\CC\cyracode\frontend"
npm run build
Output goes to frontend/dist/ — these are the static files to deploy.

Backend (FastAPI + Uvicorn)

Run for production

cd cyracode/backend
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --

Deploy options

┌─────────────────────┬───────────────────────────────────────────────────────┐
│       Option        │                                        How                                         │
├─────────────────────┼───────────────────────────────────────────────────────┤
│ Linux VPS (systemd) │ Create a systemd service to run uvicorn, use Nginx as reverse proxy                │
├─────────────────────┼───────────────────────────────────────────────────────┤
│ Docker              │ Build an image, run on any cloud (AWS ECS, GCP Cloud Run, etc.)                    │
├─────────────────────┼───────────────────────────────────────────────────────┤
│ Railway / Render    │ Push repo, point start command to uvicorn app.main:app --host 0.0.0.0 --port $PORT │
├─────────────────────┼───────────────────────────────────────────────────────┤
│ AWS EC2             │ SSH in, run with gunicorn or uvicorn behind Nginx                                  │
└─────────────────────┴───────────────────────────────────────────────────────┘
